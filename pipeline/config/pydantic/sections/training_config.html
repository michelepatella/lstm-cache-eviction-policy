Module src.pipeline.config.pydantic.sections.training_config

training_config.py

Configuration section for the model training process.

This module structures all parameters necessary to run the training loop, including general settings, hardware selection, and early stopping criteria.

Classes

TrainingDeviceConfig(BaseModel): Configuration for the hardware device used during training. TrainingGeneralConfig(BaseModel): General configuration for training run parameters. TrainingEarlyStoppingConfig(BaseModel): Criteria for early termination of training. TrainingConfig(BaseModel): Aggregates all training configuration settings.
